# Texas Holdem Workspace

目前專案已整理成：

```txt
Texas_Holdem/
  frontend/
  backend/
```

## 啟動指令

在根目錄執行：

```bash
npm run frontend
```

或：

```bash
npm run start
```

啟動後端：

```bash
npm run backend
```

前端 build：

```bash
npm run build
```

## 目錄說明

- `frontend/`：React + Vite 前端
- `backend/`：登入與收藏 API
