# Texas Hold'em Workspace

多人德州撲克遊戲平台，採前後端分離架構。

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- WebSocket

### Backend
- Node.js
- Express
- WebSocket

---

## Features

- 玩家登入
- 建立 / 加入房間
- 即時多人同步
- 發牌流程
- Betting Flow
- Dealer 控制
- 收藏功能 API
- RWD 支援

---

## Project Structure

Texas_Holdem/
├── frontend/   React + Vite
└── backend/    Node.js API

---

## Run

npm install

前端：

npm run frontend

後端：

npm run backend

全部：

npm run start

Build：

npm run build
